# MVP-001

## Alcance

Un único usuario operativo y máximo un job simultáneo. Flujo: browser → URL PUT prefirmada S3 → ffprobe → extracción de audio → transcripción real OpenAI con timestamps → Clip Brain V0 → FFmpeg 1080x1920 → subtítulos quemados → outputs S3 → reproducción/descarga desde UI.

## Arquitectura implementada

NestJS con arquitectura hexagonal pragmática por features. Cada frontera externa tiene puerto/adaptador dentro de su feature: `storage`, `media`, `transcription`, `clip-brain`, `rendering`; `jobs` orquesta el flujo y mantiene la state machine. No hay microservicios, colas, Redis ni persistencia adicional en V0.

## Decisiones

- Feature-first; no carpetas globales gigantes por capa.
- Estado de jobs en memoria: suficiente para un único job y evita SQLite hasta que reinicios durante jobs sean un requisito real.
- Upload directo por URL S3 prefirmada; el backend no recibe el video completo en memoria.
- `whisper-1` por defecto para timestamps de palabras/segmentos; configurable por ENV.
- `OPENAI_CLIP_MODEL` configurable; salida JSON Schema estricta.
- Crop central 9:16. Sin face/speaker tracking.
- Subtítulos SRT generados desde timestamps reales y quemados por FFmpeg.
- Outputs y transcript durable en bucket; temporales solo en `/tmp`.

## Exclusiones

Login, pagos, multiusuario, publicación social, scheduler, analytics, predictor de viralidad, face tracking, traducción, voice cloning, B-roll, música, templates, timeline editor, app móvil y créditos.
